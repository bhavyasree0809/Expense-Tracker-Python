Expense Management System 💰

📌 Project Description

The Expense Management System is a Python-based application designed to track daily expenses, organize spending by category, set a monthly budget, and generate monthly expense reports.

✨ Features

- Add expenses with names, amounts, categories, and dates.
- View all recorded expenses.
- Calculate total expenditure.
- Summarize spending by category.
- Set a monthly spending budget.
- Track current-month spending against the budget.
- Display remaining budget.
- Alert users when spending exceeds the budget.
- Generate monthly expense reports.
- Validate expense amounts and dates.

🛠️ Technologies Used

- Python 3
- Lists and dictionaries
- The built-in "datetime" module
- Functions and loops
- Conditional statements
- Exception handling

🚀 How to Run

1. Open an online Python compiler such as Programiz.
2. Create a file named "main.py".
3. Paste the Python source code.
4. Click Run.
5. Select an option from the menu to manage expenses.

📋 Menu Options

Option| Function
1| Add Expense
2| View Expenses
3| Show Total Expenditure
4| Category Summary
5| Set Monthly Budget
6| Monthly Expense Report
7| Exit

⚠️ Limitations

- The simplified version stores expenses temporarily in memory.
- Expense records reset when the program restarts.
- The application uses a command-line interface.
- Budget tracking is based on the current calendar month.
