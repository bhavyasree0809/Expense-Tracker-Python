
# Expense Tracker - Version 3

## About the Project
Expense Tracker is a simple Python project used to record and manage daily expenses.

## Features
- Add expenses
- View expense history
- Calculate total expenses
- Categorize expenses
- View category-wise spending summary
- Validate expense amounts
- Handle invalid menu choices

## Technologies Used
- Python 3
- Lists and Dictionaries
- Functions
- Loops and Conditions
- Exception Handling

## How to Run
1. Install Python 3.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run the command:

```bash
python expense_tracker.py
```

## Menu Options
1. Add Expense
2. View Expenses
3. Show Total
4. Category Summary
5. Exit

## Version
Version 3.0

## Limitation
Expenses are stored in memory and will be lost when the program closes.
