# Plain Expense Engine CLI

A robust financial management application operating strictly in plain-text environments. It features automated persistence, spending ceilings, and time-bracketed reports without using local currency characters or visual emojis.

## Features
- Permanent local storage via an automatic JSON data pipeline
- Monthly expense report clustering based on input timestamps
- Static budget ceilings with calculated margin warnings
- Comprehensive validation trees across all main menu pathways

## Requirements
- Python 3.6 or higher

## Setup
1. Save the code bundle down into a file named `expense_tracker.py`.
2. Run the application from your terminal console:
   ```bash
   python expense_tracker.py
   ```
